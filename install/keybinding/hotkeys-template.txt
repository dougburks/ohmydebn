# Your own OhMyDebn hotkeys.
#
# This file lives at ~/.config/ohmydebn/hotkeys.txt. It is applied on top of
# the stock hotkeys every time ohmydebn-update runs, whenever you change it,
# and whenever you run ohmydebn-hotkeys-apply. Copy it to another OhMyDebn
# machine and run ohmydebn-hotkeys-apply there to get the same hotkeys.
#
# Edit it with:   ohmydebn-hotkeys-edit   (OhMyDebn menu > Setup > Hotkeys)
# Apply it with:  ohmydebn-hotkeys-apply
#
# It is read as a bash script by your own user, so keep the quoting exactly
# as in the examples. Lines starting with # are comments; remove the # to
# activate an example. Key names are Cinnamon's: <Super> <Ctrl> <Alt>
# <Shift>, letters, digits, Return, space, F1..F12, Page_Up, KP_1, and so on.
# Several keys for one hotkey: "['<Super>R', '<Super><Alt>space']".
#
# Stock hotkeys are addressed by NAME. Names are the first quoted field in
#   /usr/share/ohmydebn/install/keybinding/keybinding-custom.txt
# for example "Browser", "Neovim", "X", "Visual Studio Code".
# Lines pasted from that file work here too (the number is ignored).
#
# Note: the Super + K hotkeys page lists the stock hotkeys only.

# ---------------------------------------------------------------------------
# hotkey NAME COMMAND BINDING
#   A new name adds a hotkey. A stock name changes that stock hotkey's
#   command and/or key in place. Any key you use here is automatically
#   removed from whichever stock hotkey had it before.

# hotkey "Slack" "/usr/share/ohmydebn/bin/ohmydebn-launch-webapp https://slack.com" "['<Super>S']"
# hotkey "Neovim" "/usr/share/ohmydebn/bin/ohmydebn-neovim" "['<Super>V']"
# hotkey "Browser" "/usr/bin/firefox" "['<Super>B']"

# ---------------------------------------------------------------------------
# hotkey-unbind NAME
#   Remove a stock hotkey's key entirely.

# hotkey-unbind "X"

# ---------------------------------------------------------------------------
# hotkey-cinnamon SUBSCHEMA KEY BINDING
#   Change one of Cinnamon's own shortcuts (window manager, media keys...).
#   Same arguments as /usr/share/ohmydebn/install/keybinding/keybinding-cinnamon.txt;
#   list the keys with:  gsettings list-recursively org.cinnamon.desktop.keybindings.wm
#   Use "[]" to remove a Cinnamon shortcut. Keys taken by a Cinnamon shortcut
#   are not freed automatically - unbind them here yourself if they clash.

# hotkey-cinnamon "wm" "close" "['<Alt>F4']"
# hotkey-cinnamon "wm" "switch-to-workspace-1" "[]"
